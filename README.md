## 6. Compilation and Execution

Open the required task folder in the terminal.

Compile a C program using:

```bash
gcc -Wall -Wextra Task01.c -o Task01.exe
```

Run the compiled program in PowerShell:

```powershell
.\Task01.exe
```

Replace `Task01` with the relevant task number and source file name.

Some tasks may require additional input files. Keep those files in the corresponding task folder before execution.
